# Prompt Router 设计规格

日期：2026-08-27  
状态：待用户确认

## 1. 目标

做一个 Mac/Windows 都能运行的本地优先桌面工具，用于：

1. 保存和编辑个人提示词；
2. 通过全局快捷键快速搜索、预览、修改并插入提示词；
3. 输入普通问题后，自动选择合适的提示词并填入问题；
4. 通过用户指定的本地同步目录，在多台设备之间同步提示词文件。

第一版不自动发送问题，不强制绑定某一家 AI，也不引入账号和自建服务器。

## 2. 选定方案

采用独立跨平台桌面应用，第一版使用 Electron + TypeScript + 原生 HTML/CSS/JavaScript 界面。

选择理由：

- 当前工作区已有 Node/pnpm 环境，能快速做出可运行原型；
- Electron 可同时覆盖 macOS 和 Windows 的全局快捷键、剪贴板、窗口和系统托盘；
- 原生界面足够完成第一版，不为引入 UI 框架增加额外复杂度；
- 后续如果需要更小体积，再评估迁移到 Tauri，不影响提示词文件格式和路由接口。

## 3. 核心使用流程

### 3.1 搜索插入

1. 用户在任意应用按全局快捷键；
2. 弹出居中的快速面板，焦点自动进入搜索框；
3. 用户输入名称、分类、标签或用途；
4. 选择提示词后，可直接使用或先编辑变量；
5. 应用把结果复制到剪贴板，并尝试向原输入框发送 Cmd/Ctrl+V；
6. 如果系统权限或目标应用不支持自动粘贴，保留剪贴板内容并明确提示用户手动粘贴。

### 3.2 自动匹配

1. 用户输入一个普通问题；
2. 路由器先根据提示词元数据、关键词、分类和问题文本做本地评分；
3. 若最高分足够高，直接展示候选提示词；
4. 若没有明显候选，且用户配置了 AI 服务，再调用兼容 OpenAI API 的分类接口；
5. 展示匹配理由和候选结果，不静默替用户发送；
6. 用户确认后再填充问题并插入当前输入框。

## 4. 提示词文件格式

每个提示词一个 Markdown 文件，便于用户直接在 Obsidian、VS Code 或文本编辑器里修改。

示例：

```markdown
---
id: decision-steelman
name: 双向钢人论证
description: 适合犹豫不决、需要比较两个选项的决定
category: 决策
keywords: [犹豫, 选择, 决定, 对比]
variables: [问题, 选项A, 选项B, 目标, 现实约束]
---

我需要做的决定是：【问题、两个选项、目标和现实约束】。
...
```

应用负责读取和写回已知元数据与正文，未知字段原样保留或提示冲突，不擅自删除用户手写内容。

## 5. 模块边界

- `prompt-store`：扫描提示词目录、解析 Markdown、保存修改、监听文件变化；
- `prompt-search`：按名称、分类、标签、关键词和正文做本地搜索；
- `prompt-router`：规则评分、候选排序、AI 兜底分类和手动覆盖；
- `prompt-renderer`：填充变量，生成最终可粘贴文本；
- `desktop-shell`：全局快捷键、快速面板、托盘、剪贴板和窗口生命周期；
- `paste-adapter`：macOS 和 Windows 的自动粘贴适配，失败时降级为剪贴板；
- `settings`：提示词目录、快捷键、AI 服务配置和用户偏好。

各模块通过明确的数据对象通信，路由器不直接操作窗口，窗口不直接读写文件。

## 6. 本地保存与同步

默认提示词目录位于应用数据目录，但首次使用允许用户选择一个外部目录。用户可以把该目录放入 iCloud、OneDrive 或其他同步盘。

第一版只负责安全地读写文件，不实现云端账号和复杂冲突合并。检测到文件在外部发生变化时重新加载；保存前创建一次本地备份，避免同步冲突导致内容直接丢失。

API key 使用操作系统安全存储，不写入提示词文件或普通配置文件。

## 7. 第一版范围

包含：

- 提示词列表、搜索、分类和编辑；
- 全局快捷键唤起快速面板；
- 直接使用、预览修改、复制和自动粘贴；
- 本地规则路由；
- 可选的 OpenAI-compatible AI 路由兜底；
- 自定义提示词目录；
- 最近使用记录和手动指定候选；
- macOS 开发运行和 Windows 构建配置。

不包含：

- 自动向 ChatGPT、Claude 或其他服务发送消息；
- 账号系统、云端数据库和多人协作；
- 自动改写提示词正文；
- 复杂的版本控制界面；
- 后台持续读取用户所有输入内容。

## 8. 错误与安全策略

- 没有匹配结果时，明确显示“未找到可靠匹配”，不强行套用；
- AI 路由不可用时回退到本地规则和手动搜索；
- 自动粘贴失败时回退到剪贴板，并告诉用户当前状态；
- 解析失败的文件保留原文件，列入错误列表，不覆盖；
- 外部同步发生冲突时不静默合并，保留备份并提示用户处理；
- 默认不记录用户输入的问题正文，只记录必要的本地使用次数；
- API 请求前显示服务提供方，避免用户误以为完全本地处理。

## 9. 验收标准

1. 在 macOS 上按快捷键可以在 1 秒内打开快速面板；
2. 能搜索并编辑一个 Markdown 提示词，重启应用后内容仍存在；
3. 能在 TextEdit、浏览器和终端中完成自动粘贴，权限不足时能可靠复制到剪贴板；
4. 对“我在两个显示器之间不知道怎么选”这类输入，能优先识别双向钢人论证提示词；
5. 规则无法判断时，未配置 AI 也不会报错或假装已经完成自动判断；
6. 把提示词目录放入同步盘后，外部修改能够被应用重新加载；
7. 同一份提示词文件可以在 Windows 上直接打开和编辑；
8. 至少有针对文件解析、搜索排序、变量填充和路由降级的自动化测试。

## 10. 后续演进

第一版稳定后，再根据实际使用频率决定是否增加：

- 更细的路由学习和反馈按钮；
- Prompt 版本历史；
- 内置模板市场或 GitHub 导入；
- Tauri 体积优化；
- 更完善的 Windows/macOS 输入注入适配。
