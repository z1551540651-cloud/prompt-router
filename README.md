# Prompt Router

一个本地优先的个人提示词快速调用工具，支持 macOS 和 Windows。

## 当前能力

- 内置你提供的 12 个提示词模板；
- 提示词以 Markdown 文件保存，可在应用、Obsidian 或编辑器里修改；
- 全局快捷键 `⌘/Ctrl + Shift + Space` 唤起面板；
- 搜索提示词，预览后复制并尝试粘贴到原输入框；
- 输入普通问题，由本地意图规则自动推荐提示词；
- 没有可靠匹配时保留候选并要求手动确认，不强行套用；
- 复制前预览已经填入用户问题的完整提示词，也可以复制原始模板；
- 可从设置按钮选择 iCloud、OneDrive 或其他同步目录。

点击“使用”或“生成并复制”后，程序会先显示完整提示词预览。确认复制后，程序会尝试粘贴到呼出面板前的输入框。若目标应用不支持自动粘贴，面板会重新显示，并提示你手动粘贴。

## 运行

```bash
pnpm install
pnpm build
pnpm start
```

首次启动时，程序会把内置模板复制到 Electron 的用户数据目录。点击右上角设置按钮，可以切换到自己的同步目录。

## macOS 权限

为了让程序把结果自动粘贴到之前的输入框，需要在“系统设置 → 隐私与安全性 → 辅助功能”中允许 Prompt Router 控制电脑。如果没有授权，程序仍会把结果放进剪贴板，你可以手动粘贴。

Windows 使用 PowerShell 的键盘模拟完成自动粘贴；遇到管理员权限窗口或特殊输入框时，也会退回剪贴板。

## 修改提示词

每个模板都是一个 Markdown 文件，格式如下：

```markdown
---
id: example
name: 示例提示词
description: 用途说明
useWhen: 适用于什么情况
category: 决策
keywords: [选择, 对比]
variables: [问题, 目标]
intent: decision
positiveExamples: [我在两个选项之间犹豫, 这个产品值不值得买]
negativeExamples: [请解释这个概念]
primaryVariable: 问题
---

提示词正文，支持【问题】和 {{目标}} 两种变量写法。
```

保存前应用会生成同名 `.bak` 备份。无法解析的文件不会被覆盖。

## 自动匹配

当前版本完全使用本地规则，不要求 API Key，不会自动向 ChatGPT、Claude 或其他服务发送问题。匹配顺序是：

1. 识别问题更接近理解概念、做选择、核查事实、拆解成品、系统研究或其他意图；
2. 结合每条提示词的适用示例、不适用示例、关键词和用途说明评分；
3. 使用反向证据排除容易混淆的提示词；
4. 最高分达到阈值并与第二名拉开差距时，才显示为高置信度匹配；
5. 没有证据时明确显示“暂时无法判断”，不拿提示词库开头几条冒充结果。

点击“生成并复制”后，用户问题会填入该提示词的主要字段，其他缺失字段会标记为“（暂未提供）”。程序只整理现有模板，不会编造用户没有提供的背景、事实或约束。

当前版本固定运行 100 题本地回归测试：96 个明确问题检查高置信度 Top-1 匹配，4 个模糊问题检查是否保持人工选择。

## 构建安装包

```bash
pnpm dist:mac
pnpm dist:win
```

macOS 签名、公证和 Windows 安装包的最终构建，需要在对应平台配置签名证书后进行。

项目包含 GitHub Actions 发布流程。推送形如 `v0.1.0` 的版本标签后，会在 GitHub Release 中生成 macOS 和 Windows 安装包。
